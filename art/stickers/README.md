# Dear Diary starter stickers

24 original vector illustrations made for Dear Diary. No Pinterest artwork, external clip art, fonts, logos or other third-party image assets were used. The screenshots supplied by the user were mood references only.

Source: the SVG files in this directory. App assets: lossless transparent 256px WebP files in public/stickers.
